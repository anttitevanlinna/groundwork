# The Big Picture

A navigable **pattern language** for builder-leaders putting AI agents to work — and crossing the wall from *personal* capability to *team and company* value.

Two surfaces, one corpus:

- **The map** — [`site/index.html`](site/index.html): a single-screen canvas. Every node is a door.
- **The field guide** — [`site/whitepaper.html`](site/whitepaper.html): the same 37 patterns, read straight through along the value cycle.

Each pattern is a recurring situation welded to the move that resolves it — *Use when · Core moves · Build · Test · Why* — with a picture and links to its neighbours. The contract is the opposite of a consulting deck: evidence not dogma, launchpad not cage. The bet is simple — **action beats thinking; you build capability by acting under uncertainty.**

Published with GitHub Pages from the `site/` directory.
