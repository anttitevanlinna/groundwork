The principle: the tool that builds tools compounds — an agent that can author agents folds its own output back into its capability; every other tool you build sits inert.

Once a compounding system holds real evidence, stop deciding the next agent from a blank page. Make the current system propose it — then interrogate that proposal with three named thinking disciplines before you commit. It is the closing turn of the personal → company arc: a personal operating system that proposes its own next move, run at room scale, becomes an organisational way to set the next bet.

The blank page is the enemy. The system holds more evidence than the room — and the gates bend the bad bet before you build it.

The mechanism · who proposes, who interrogates

The system is a better starting author than the room.

Picture a builder-leader with eight weeks of compounding behind them: a memory that maintains a picture, agents that read it, skills that audit the agents, judges that catch the skills drifting. Each addition raised a ceiling. Then the question arrives unasked — where is this all going, and what do I build next? The reflex is to brainstorm from a blank doc in a meeting, or worse, copy the obvious roadmap everyone in the category is already building. Both start from the wrong place: a room remembers less than the system does.

So don't open the blank doc. Point the agent at its own memory, its sources, and the standing strategic question, and ask it to suggest the next agent to build. The proposal arrives grounded in what the system actually holds, not in what the loudest person in the meeting recalls. This inverts the usual order: the human stops being the author of the first draft and becomes the editor of a draft the system wrote — which is a far better job to have, because editing a wrong-but-grounded proposal is faster than conjuring a right one from nothing.

The danger is obvious the moment you say it out loud: a system proposing its own next move will happily propose the comfortable one. Left unchecked, the flywheel amplifies a bad bet as smoothly as a good one — precision compounds, and so does blur. The brake is three thinking disciplines you run on the proposal, by name. These are not installed skills or props you procure; they are portable postures borrowed from people who studied decision-making, and you ask Claude to run them on any decision too big to eyeball.

Make it propose, then interrogate the proposal before you trust it. The system writes the draft; the disciplines decide whether it survives.

The named components · three disciplines that travel

Crux, what-would-have-to-be-true, pre-mortem.

These three are the well-grounded, travelling components of this pattern — the part that holds up even where the "self-building system" framing is still a direction. They are moves you can carry to any big decision, agent or not. The cross-check is what makes the proposal read sharper than the initial stance: force each surviving proposal to notice the evidence that argues against it, and the comfortable bet either earns its place or falls.

The brake on the obvious failure · run all three, by name

Crux

Rumelt

What is the one hard thing this actually turns on? Strip the proposal to the single difficulty it lives or dies on — most plans hide it.

What would have to be true?

Roger Martin

For this to be the right bet, what must hold? Name the conditions; then you know which ones to test rather than assume.

Pre-mortem

Klein & Kahneman

Assume it failed within a month. Why? Working backwards from the obituary surfaces failure modes a forward plan glosses past.

What survives the disciplines and the cross-check gets collapsed into something small: a strategy kernel, a suggested agent set, and a two-week plan. Then say the quiet part. The plan you just produced is a set of assumptions dressed as work. Name them as assumptions; start the concurrent pieces; design experiments for the uncertain ones. A plan that pretends its assumptions are facts is the same blank-page brainstorm wearing a kernel's clothes — the labelling is what keeps the round honest.

The compounding loop · what changes between rounds

The cycle that sharpened the kernel is the one that sharpens it again next month.

After the round, have the system rewrite the single most load-bearing file — the kernel, the agent-set rules, or the rules that governed how the agents argued — quoting before-and-after for every change. This is the ⟲ of the pattern: the same flywheel turning on the next problem, and the one after. Code-generating agents are the one category where building a tool genuinely makes the next tool faster to build; every other tool you build sits inert. So the kernel comes back to the next round visibly richer, and the round after that starts from a sharper place than this one did.

Run it tonight on the agent with the most memory. Ask one question: "Given everything in your memory and sources, what's the next agent I should build, and why?" Test · how you know the round was worth running

Three quick reads, plus one that catches theatre. The plan disagrees with at least one obvious option — if it just ratified the roadmap everyone already had, the system added nothing. It names the first assumption that could break — the pre-mortem produced a real failure mode, not a reassurance. And it is small enough to run next — a two-week shape, not a strategy deck.

The falsifiable check: name one critique raised in the round that did not change the rewritten file, and quote the critique against the line it left standing. If every critique conveniently confirmed the synthesizer, the round was theatre — agents reading agents and nodding. A real round leaves scars in the file.

The blank page is the enemy because it throws that accumulated evidence away and starts from a room's memory instead.

Crux, what-would-have-to-be-true, and pre-mortem are the brake — they stop the flywheel amplifying a bad bet as smoothly as a good one, because precision compounds and so does blur. Underneath it all sits one grounding rule: every agent publishes what it read, what it couldn't find, and what it inferred without a source. Skip that, and agents reading agents smoothly hallucinate each other's memory.
